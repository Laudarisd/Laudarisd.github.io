## 5. Project Detail Pages / 프로젝트 상세 페이지

Each major project should have its own page.

Include:

1. **Overview / 프로젝트 소개**
2. **Problem & Objective / 문제 및 목표**
3. **My Contributions / 담당 역할 및 기여**
4. **System Architecture / 시스템 아키텍처**
5. **Data & AI Pipeline / 데이터 및 AI 파이프라인**
6. **Technology Stack / 사용 기술**
7. **Results & Challenges / 주요 성과 및 해결 과제**
8. **GitHub, Demo, or Publications / 관련 링크**

Keep descriptions short, technical, and professional. Do not invent missing details.

## 6. Architecture Guidelines / 아키텍처 가이드

- Include a clear architecture diagram for major projects.
- Show the actual end-to-end workflow where applicable.
- Example: Data → Preprocessing → AI/ML → API → Deployment → Dashboard.
- Label important frameworks, models, databases, and infrastructure.
- Use simple, responsive diagrams consistent with the existing design.
- Do not invent architectural components or technologies.

## 7. Languages / 언어

- Support English (EN) and Korean (KR).
- 프로젝트 카드와 상세 페이지 모두 영어 및 한국어 지원.
- Reuse the existing language-switching system.
- Keep technical terms in English where appropriate.
- Maintain consistent information across both languages.

## 8. Coding & Design Rules / 개발 및 디자인 규칙

- **Keep code short, simple, and beginner-friendly.**
- Add clear, meaningful single-line comments.
- Avoid unnecessary abstractions, libraries, or dependencies.
- Reuse existing components, functions, and CSS.
- Do not rewrite working code unnecessarily.
- Follow the current website's visual style.
- Ensure mobile and desktop compatibility.
- Keep animations and interactions minimal.

## 9. Project Status / 프로젝트 상태

- Completed / 완료
- In Development / 개발 중
- Research in Progress / 연구 진행 중
- Proof of Concept / 개념 검증

Do not present ongoing projects as completed.

## 10. Important Restrictions / 중요 사항

- **Only modify the Projects section and related project subpages.**
- Preserve all unrelated website content and functionality.
- Treat all projects professionally, regardless of development context.
- Clearly distinguish individual contributions from team contributions.
- Protect confidential company and client information.
- Never invent metrics, results, technologies, or achievements.
- Verify that project links, architecture diagrams, and both languages work correctly.
